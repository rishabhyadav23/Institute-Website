---
name: AIS Website Design System Overview
description: Design tokens, component patterns, and tech stack for Antriksh Institute of Science website - coaching institute in Meerut
type: project
---

Brand color: Maroon palette (brand-50 through brand-950, primary brand-900 #881337).
Fonts: Outfit (headings), Plus Jakarta Sans (body). Both from Google Fonts.
Tech: React 19 + Tailwind CSS + Vite + lucide-react icons.
Dark mode: class-based toggle via useTheme hook.
Layout: max-w-7xl container, Navbar (fixed top, h-20) + Footer with newsletter.
Button variants: primary (brand-900), secondary (outline), ghost, accent (orange).
Card pattern: rounded-2xl, border, shadow-md, hover:-translate-y-1, group hover effects.
Admin panel: Separate layout (AdminLayout) with gray-900 sidebar, no dark mode support.
**Why:** This is a pre-launch coaching institute website competing with PW/Unacademy/Allen.
**How to apply:** All UI suggestions should be practical for a small team, prioritize mobile UX (Indian student audience), and maintain the maroon brand identity.
